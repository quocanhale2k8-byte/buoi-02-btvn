# Bài tập về nhà buổi 2

Hà Lê Quốc An

Trang giới thiệu workshop nến thơm, viết bằng HTML. Mở `index.html` bằng trình duyệt để xem bài; giữ nguyên thư mục `images`.

Trang gồm phần giới thiệu, danh sách hoạt động, bảng giá, ba hình ảnh và form đăng ký. Form có các kiểu input text, email, tel, date, number, radio, checkbox, submit và reset; có thêm select và textarea. Các ô bắt buộc dùng required. Form chỉ minh họa HTML, không có máy chủ lưu đăng ký.

Bố cục và ba ảnh tham khảo từ repo được cung cấp: https://github.com/thuybxg1823-glitch/BTVN-buoi2 . Nội dung và mã HTML được viết lại cho bài này. Giá và tên workshop là nội dung thực hành. Chưa có đề gốc để đối chiếu các yêu cầu ngoài repo mẫu.
